# sobre o projeto:

Este projeto foi desenvolvido com o objetivo de praticar e aprofundar meus conhecimentos em desenvolvimento web, utilizando HTML, CSS e JavaScript. A ideia é reunir exemplos, exercícios e pequenos projetos que me ajudem a compreender melhor os conceitos da programação e a desenvolver minhas habilidades na área de tecnologia.

# Objetivos

 - Praticar os conceitos fundamentais de HTML, CSS e JavaScript.
 - Desenvolver a lógica de programação por meio de exercícios práticos.
 - Organizar e documentar meus estudos.
 - Acompanhar minha evolução como desenvolvedor.

 # tecnologias utilizadas:

 - HTML5
 - CSS3
 - JavaScript
 - GitHub

# Conteúdos estudados

O projeto reúne práticas relacionadas aos conceitos que venho aprendendo durante meus estudos, como:

 - Variáveis e tipos de dados.
 - Arrays e objetos.
 - Eventos e interatividade.

# Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo index.html no navegador.
